Project Gradient Noise

3D Graphics

Project Overview

This project implements gradient noise for procedural texture generation in a real-time graphics demo. Instead of blending only random values at grid points, the algorithm assigns repeatable gradient directions, computes dot products between those gradients and local offset vectors, and interpolates the results to create smooth Perlin-style noise. The demo visualizes the generated noise as a texture so the differences between value-based and gradient-based procedural patterns can be observed directly.

Tasks Completed

  • Added and registered the Gradient Noise demo in the project.
  • Implemented repeatable hash-based lookup for gradient directions.
  • Calculated gradient dot products from lattice corners to the sampled position.
  • Implemented improved Perlin noise evaluation for smoother procedural patterns.
  • Remapped gradient noise values into a displayable texture range.
  • Generated RGBA noise data and uploaded it for real-time WebGL texture rendering.
  • Built on the Value Noise assignment to compare random-value interpolation with gradient-vector noise.
  • Embedded the working WebGL demo into this portfolio page.

Reflection

This assignment helped me understand why gradient noise produces more natural-looking procedural detail than simple value noise. The most important challenge was keeping the gradient selection deterministic while still making the texture look organic and continuous. I also learned how the dot product between a gradient vector and a distance vector gives each cell a directional influence, and how interpolation turns those local influences into a smooth final pattern.
