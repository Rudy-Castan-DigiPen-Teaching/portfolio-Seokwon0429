Project Shadow Mapping

3D Graphics

Project Overview

This project implements shadow mapping in a real-time 3D graphics demo. The scene is rendered from the light's point of view to create a depth map, and that depth information is then used during the main rendering pass to determine which parts of the scene are in shadow. The demo also includes tools for visualizing the light frustum and the generated shadow map, making it easier to understand how shadow mapping works internally.

Tasks Completed

  • Added and registered the Shadow Mapping demo in the project.
  • Implemented depth texture and RGBA texture support in the Texture class.
  • Implemented the FrameBuffer class to render the scene into a depth texture.
  • Implemented camera view and world transformation matrix calculations.
  • Rendered the scene from the light's perspective to generate a shadow map.
  • Applied shadow mapping during the main screen rendering pass.
  • Added shader logic for shadow lookup, lighting, gamma correction, and fog.
  • Added debug visualization for the light frustum and depth texture.
  • Embedded the working WebGL demo into this portfolio page.

Reflection

This assignment helped me understand how multi-pass rendering is used to create realistic shadows in real-time graphics. One of the main challenges was connecting multiple systems together, including textures, framebuffers, cameras, shaders, and the final rendering pass. I also learned how important light-space transformations are when comparing the current fragment position against the shadow map. Visualizing the depth texture and light frustum made it much easier to debug the result and understand why shadows appeared correctly or incorrectly.
