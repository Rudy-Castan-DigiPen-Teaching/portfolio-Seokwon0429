Project Value Noise

3D Graphics

Project Overview

This project implements value noise for procedural texture generation in a real-time graphics demo. The algorithm generates random values, uses permutation hashing to select repeatable samples, and blends those samples with interpolation to create smooth noise patterns. The demo visualizes the generated noise as a texture so the effect of period size, smoothing, and dimensional sampling can be observed directly.

Tasks Completed

  • Added and registered the Value Noise demo in the project.
  • Implemented value noise evaluation for 1D, 2D, and 3D coordinates.
  • Used permutation hashing to generate repeatable pseudo-random sample lookups.
  • Supported multiple period sizes and resized the stored random values when the period changes.
  • Applied smoothing methods to interpolation parameters before blending noise values.
  • Implemented linear, bilinear, and trilinear interpolation for different noise dimensions.
  • Added texture uploading support so generated RGBA noise data can update the displayed texture.
  • Created simple vertex and fragment shaders for rendering the generated noise texture.
  • Embedded the working WebGL demo into this portfolio page.

Reflection

This assignment helped me understand how randomness can become controllable visual detail when it is combined with hashing and interpolation. The most important challenge was making the noise repeatable while still appearing random, especially across different dimensions and period sizes. I also learned how changing the smoothing function affects the final texture, and how procedural data can be generated on the CPU, uploaded to a texture, and displayed through a shader in real time.
